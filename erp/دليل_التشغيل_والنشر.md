## 🚀 الطريقة الأسهل للتشغيل والمشاهدة (Docker) — موصى بها

دي أسرع طريقة تشوف البرنامج شغّال فعلياً على جهازك، بأمر واحد.

### المتطلب الوحيد
ثبّت **Docker Desktop** (مجاني):
- ويندوز/ماك: من https://www.docker.com/products/docker-desktop
- بعد التثبيت، افتح برنامج Docker Desktop وسيبه شغّال في الخلفية.

### خطوات التشغيل
1. فُك ضغط الملف في أي مكان (مثلاً على سطح المكتب).
2. افتح «الطرفية» (Terminal على ماك، أو PowerShell على ويندوز).
3. ادخل مجلد المشروع:
   ```bash
   cd Desktop/erp
   ```
   *(لو حطيته في مكان تاني، غيّر المسار)*
4. شغّل كل حاجة بأمر واحد:
   ```bash
   docker compose up --build
   ```
   أول مرة هتاخد 3–5 دقائق (بيحمّل المكتبات ويجهّز قاعدة البيانات تلقائياً).

### المشاهدة
بعد ما تشوف رسائل إن الخوادم اشتغلت، افتح المتصفح على:

| الرابط | الوظيفة |
|--------|---------|
| **http://localhost:3000** | 👈 **البرنامج نفسه** (الواجهة) |
| http://localhost:8000/api | المحرّك (للمطوّرين) |

### بيانات الدخول التجريبية
| الشركة | البريد الإلكتروني | كلمة المرور |
|--------|------------------|-------------|
| مكتب النور للمحاماة (مدير نظام) | `admin@noor.test` | `password` |
| شركة الأمل التجارية | `admin@amal.test` | `password` |

### الإيقاف
في نفس نافذة الطرفية اضغط `Ctrl + C`، أو من نافذة تانية:
```bash
docker compose down
```
> لو عايز تمسح البيانات التجريبية وتبدأ من نظيف: `docker compose down -v`

## 🛠️ الطريقة اليدوية (بدون Docker) — لو عايز تعدّل بسرعة

مفيدة لو هتغيّر في الكود وتشوف النتيجة فوراً. محتاج تفتح **نافذتين** طرفية.

### المتطلبات
- **PHP 8.3+** و**Composer** (مدير مكتبات PHP).
- **Node.js 20+** و**npm**.
- (اختياري) MySQL — مش لازم، النظام بيشتغل افتراضياً على SQLite (ملف قاعدة بسيط).

### النافذة الأولى — المحرّك (Backend)
```bash
cd erp/backend
composer install
cp -n .env.example .env
php artisan key:generate
php artisan migrate:fresh --seed     # يبني الجداول + بيانات تجريبية
php artisan serve                    # http://localhost:8000
```

### النافذة الثانية — الواجهة (Frontend)
```bash
cd erp/frontend
npm install
npm run dev                          # http://localhost:3000
```
افتح **http://localhost:3000** وادخل بنفس بيانات الدخول فوق.

## 🌍 كيف تنشره على الإنترنت (Production) عشان الناس تستخدمه؟

عندك مستويين حسب احتياجك:

### الخيار (أ) — سيرفر خاص (VPS) بأمر Docker — الأبسط والأنصح
1. اشترِ سيرفر صغير (VPS) من أي مزوّد (DigitalOcean / Hetzner / Linode / AWS Lightsail).
   مواصفات كافية للبداية: **2 CPU / 4GB RAM / Ubuntu 22**.
2. ادخل على السيرفر وثبّت Docker:
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```
3. ارفع مجلد `erp` على السيرفر (بـ `scp` أو من GitHub).
4. **مهم — قبل التشغيل الفعلي اعمل التعديلات الأمنية دي:**
   - في `docker-compose.yml` غيّر كلمة مرور قاعدة البيانات `MYSQL_ROOT_PASSWORD` لكلمة قوية.
   - في ملف `backend/.env` اضبط:
     ```
     APP_ENV=production
     APP_DEBUG=false
     APP_URL=https://your-domain.com
     ```
   - غيّر كلمات مرور المستخدمين التجريبيين من داخل البرنامج (أو من قاعدة البيانات).
5. شغّل:
   ```bash
   docker compose up --build -d      # -d = يشتغل في الخلفية
   ```
6. **اربط دومين + شهادة HTTPS مجانية** عبر «بروكسي عكسي» (Nginx Proxy Manager أو Caddy)
   عشان الناس تدخل على `https://your-domain.com` بأمان. ده أهم خطوة أمنية للنشر العام.

### الخيار (ب) — استضافة احترافية منفصلة (للتوسّع)
- **المحرّك (Laravel):** على Laravel Forge / Railway / Render، مع **MySQL مُدار**.
- **الواجهة (React):** تتبني بأمر `npm run build` (بيطلع مجلد `dist`) وترفعها على
  Netlify أو Vercel أو Cloudflare Pages (استضافة ثابتة سريعة).
- في الواجهة، اضبط عنوان الـ API ليشير لرابط المحرّك على الإنترنت.

### نصائح أمان أساسية قبل أي نشر عام
- ✅ غيّر كل كلمات المرور الافتراضية.
- ✅ `APP_DEBUG=false` دايماً في الإنتاج.
- ✅ فعّل HTTPS (شهادة SSL) — إجباري لأي بيانات حساسة.
- ✅ اعمل **نسخة احتياطية يومية** لقاعدة البيانات.
- ✅ خلّي قاعدة البيانات مش متاحة من الإنترنت مباشرة (بس من السيرفر).

## 🆘 حل المشاكل الشائعة

| المشكلة | الحل |
|---------|------|
| `docker: command not found` | Docker Desktop مش متثبّت أو مش شغّال — افتحه واستنى يكمّل تشغيل. |
| المنفذ 3000 أو 8000 مشغول | اقفل البرنامج اللي ماسكه، أو غيّر الأرقام في `docker-compose.yml`. |
| الواجهة بتفتح بس مفيش بيانات | تأكد إن المحرّك شغّال (http://localhost:8000/api) وإن السطر `--seed` اشتغل. |
| نسيت كلمة المرور التجريبية | هي `password` لكل الحسابات التجريبية. |
| عايز تبدأ من بيانات نظيفة | `docker compose down -v` ثم `docker compose up --build`. |
