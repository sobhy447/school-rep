# 🗂️ محتويات نظام ERP المحاسبي بالكامل — دليل الموديولات والإمكانيات

> هذا الملف يشرح **كل موديول** (قسم) في البرنامج، و**إيه اللي تحته** من شاشات
> وأوامر وإمكانيات. مرتّب بنفس ترتيب القائمة الجانبية اللي بتشوفها في البرنامج.
>
> **رموز تساعدك:** 📄 شاشة/قائمة · ⚙️ أمر/إجراء · ✅ إمكانية · 🔒 محمي بصلاحية

---

## 🧱 إمكانيات عامة تسري على كل النظام (الأساس)

- ✅ **تعدد الشركات (مستأجرين):** نظام واحد يخدم شركات كتير، كل شركة تشوف بياناتها هي
  بس — عزل كامل لا يقدر أحد يخترقه (كل سجل مربوط بـ `company_id`).
- ✅ **التبديل بين الشركات** من داخل البرنامج بضغطة (لمن له صلاحية).
- ✅ **الصلاحيات (RBAC):** لكل موديول **10 صلاحيات** دقيقة:
  عرض · إضافة · تعديل · حذف · اعتماد · ترحيل · عكس · إقفال · طباعة · تصدير.
- ✅ **الأدوار الجاهزة:** مدير النظام · مدير مالي · محاسب (بدون حذف/إقفال) · كاشير
  (سندات + عملاء فقط) — وتقدر تصمّم أدوار جديدة بنفسك.
- ✅ **تسجيل دخول آمن** بـ «تذكرة دخول» (Token) + تسجيل خروج.
- ✅ **سجل تدقيق** يسجّل كل عملية حساسة (مين عمل إيه وإمتى والقيمة قبل/بعد).
- ✅ **واجهة عربية (RTL)** + **وضع ليلي** 🌙 + **متجاوبة مع الموبايل**.
- ✅ **إشعارات فورية** لكل عملية (نجاح/خطأ) + **هياكل تحميل** أثناء جلب البيانات.
- ✅ **العملة:** الدينار الكويتي (3 خانات عشرية) · **الضريبة:** معطّلة افتراضياً وقابلة للتفعيل.
- ✅ **قاعدة ذهبية:** كل التقارير تُبنى من **القيود المُرحَّلة والمتوازنة فقط**.

## 📊 1) لوحة المؤشرات (Dashboard)

📄 **الشاشة الرئيسية** أول ما تدخل.
- ✅ بطاقات لحظية: إجمالي الأصول · الخصوم · حقوق الملكية + النتيجة · صافي الربح/الخسارة ·
  الإيرادات · المصروفات · صافي التدفق النقدي.
- ✅ **رسم بياني** للإيرادات والمصروفات شهرياً.
- ✅ مؤشر **«الميزانية متوازنة»** (أصول = خصوم + حقوق ملكية) — طمأنة فورية إن الدفاتر سليمة.

## 🧮 2) المحاسبة

### 🌳 2-أ) دليل الحسابات (Chart of Accounts) 🔒 `accounts`
📄 شجرة الحسابات + نموذج إضافة حساب.
- ⚙️ **إضافة / تعديل / حذف** حساب.
- ✅ شجرة **غير محدودة المستويات** (الأب تصنيف فقط لا يقبل حركة، الحركة على الحسابات الورقية).
- ✅ **نوع الحساب** (أصول/خصوم/حقوق ملكية/إيراد/مصروف) يحدّد **طبيعته** (مدين/دائن)
  و**قائمته المالية** (الميزانية/قائمة الدخل) **تلقائياً** حسب القواعد العالمية.
- ✅ **رصيد افتتاحي** (مدين/دائن) لكل حساب.
- ✅ **ترحيل الأرصدة من الأسفل لأعلى** (رصيد الأب = مجموع أبنائه).
- ✅ **منع الأخطاء:** منع الدوائر، وتطابق نوع الابن مع الأب.
- ✅ **العملاء والموردون** حسابات داخل الشجرة (تصنيف الطرف) + **كشف حساب** برصيد جاري.
- ⚙️ **استيراد شجرة حسابات قديمة** (معاينة بالأخطاء ثم تنفيذ).
- ⚙️ **بحث ذكي** في الحسابات.
- ⚙️ **طباعة كشف حساب PDF** (مع إمكانية ضم المرفقات).
- ✅ **تعدد الفئات** (مجموعات: نوع العميل/التابع له…) + **بيانات تفصيلية مرنة** لكل حساب.

### 📝 2-ب) قيد اليومية (Journal Entries) 🔒 `journals`
📄 شاشة إدخال قيد (رأس + أسطر) + قائمة القيود الأخيرة.
- ⚙️ **إنشاء / تعديل / حذف / تكرار (نسخ)** قيد.
- ⚙️ **دورة حياة القيد:** مسودة → **اعتماد** → **ترحيل** → **عكس**.
- ✅ أسطر **غير محدودة**، كل سطر **مدين أو دائن** (مش الاتنين)، و**التوازن إلزامي**
  (الزر لا يعمل لو غير متوازن).
- ✅ **مركز تكلفة أساسي** + **مركز تكلفة إضافي** (الإضافي يستدعي الحساب واسم الخصم تلقائياً).
- ✅ **بحث ذكي بالحساب (F1)** أثناء الكتابة · **ترقيم تلقائي** للقيد.
- ⚙️ **مرفقات (📎):** رفع PDF وربط كل سطر برقم/مدى صفحات (لطباعة الكشف بمرفقاته).
- ⚙️ **طباعة القيد PDF**.

### 🧾 2-ج) السندات (قبض/صرف/تحويل) 🔒 `vouchers`
📄 شاشة سند (قبض/صرف) + قائمة السندات.
- ⚙️ **إنشاء سند** قبض أو صرف أو تحويل.
- ✅ السند **يُنشئ قيده المحاسبي ويُرحَّل تلقائياً** (الجانب الرئيسي نقدية/بنك).
- ⚙️ **عكس** سند · **مرفقات (📎)** · **طباعة PDF**.

## ⚙️ 3) العمليات

### 💼 3-أ) العهد (Petty Cash) 🔒 `petty_cash`
📄 بنود العهدة + كشوف المصروفات.
- ⚙️ **بنود العهدة** (إضافة/تعديل/حذف) بحدود تكرار (منع نهائي عند التجاوز).
- ⚙️ **كشف مصروفات** → **اعتماد** → **تحويل لقيد مُرحَّل** يخصم حساب العهدة تلقائياً.

### 🔴 3-ب) الأمانات والسداد (Trust & Settlements) 🔒 `settlements`
📄 شاشة مطابقة (أمانات بالأحمر / استحقاقات بالأصفر).
- ✅ طبقة مطابقة منفصلة بين **الأمانات** و**الاستحقاقات**.
- ⚙️ **سداد جزئي / كامل / زائد** + ملخص لكل عميل.

### 🏗️ 3-ج) الأصول الثابتة والإهلاك (Fixed Assets) 🔒 `fixed_assets`
📄 تسجيل الأصول + جدول بالقيمة الدفترية + تشغيل الإهلاك.
- ⚙️ **إضافة / تعديل / حذف** أصل (تكلفة، قيمة تخريدية، عمر، طريقة).
- ✅ طريقتا إهلاك: **قسط ثابت** و**متناقص**.
- ⚙️ **إهلاك أصل واحد** أو **إهلاك كل الأصول** لفترة → بقيد تلقائي مُرحَّل
  (مدين مصروف الإهلاك / دائن مجمع الإهلاك) + **منع تكرار نفس الفترة**.
- ⚙️ **جدول إهلاك تقديري** لكل أصل · **استبعاد/بيع** الأصل بقيد يحسب الربح/الخسارة.

### 🏦 3-د) البنوك والتسويات (Bank Reconciliation) 🔒 `banks`
📄 شاشة تسوية بنكية + استيراد كشف البنك.
- ⚙️ **إنشاء تسوية** ومطابقة حركات حسابك البنكي مع كشف البنك.
- ⚙️ **استيراد كشف البنك (CSV)** · **تأشير المُسوّى** · حساب الفرق · **إتمام التسوية** عند التطابق.

### 🧾 3-هـ) الشيكات (Cheques) 🔒 `cheques`
📄 تسجيل شيك + قائمة الشيكات بحالاتها.
- ⚙️ **تسجيل شيك** وارد (تحصيل) أو صادر (صرف).
- ⚙️ **تحصيل/صرف** الشيك أو **ارتداد** (Bounce) — بقيود تلقائية.
- ✅ حالات: منتظر · محصّل/مصروف · مرتد · ملغى.

### 📦 3-و) المخزون (Inventory) 🔒 `inventory`
📄 تبويبات: الأصناف · المخازن · الحركات · التقييم.
- ⚙️ **أصناف** (إضافة/تعديل/حذف، سعر شراء/بيع، حد إعادة طلب).
- ⚙️ **مخازن** متعددة.
- ⚙️ **حركات:** استلام · صرف · تحويل بين مخازن · تسوية.
- ✅ تقييم بـ **متوسط التكلفة المرجّح** + **تقرير تقييم المخزون** الإجمالي.

### 🛒 3-ز) المشتريات (Purchases) 🔒 `purchases`
📄 فواتير الموردين.
- ⚙️ **إنشاء فاتورة مشتريات** → **ترحيل** يُنشئ **حركة مخزون + قيد متوازن تلقائياً**
  (مخزون + ضريبة مدخلات / المورد).
- ⚙️ **طباعة فاتورة PDF**.

### 🧾 3-ح) المبيعات (Sales) 🔒 `sales`
📄 فواتير العملاء.
- ⚙️ **إنشاء فاتورة مبيعات** → **ترحيل** يُنشئ قيداً متوازناً
  (العميل/الإيراد + ضريبة مخرجات + تكلفة بضاعة مباعة/مخزون).
- ⚙️ **طباعة فاتورة PDF**.

### ↩️ 3-ط) المرتجعات (Returns) 🔒 `returns`
📄 مرتجعات المبيعات والمشتريات.
- ⚙️ **تسجيل مرتجع** (مبيعات أو مشتريات) بقيد عكسي تلقائي وأثر مخزني.

### 👥 3-ي) الموارد البشرية والرواتب (HR & Payroll) 🔒 `hr`
📄 تبويبات: الموظفون · مكوّنات الراتب · المسيّرات.
- ⚙️ **موظفون** (إضافة/تعديل/حذف) + **ربط مكوّنات راتب** لكل موظف.
- ⚙️ **مكوّنات راتب** (بدلات/استقطاعات).
- ⚙️ **توليد مسيّر** لفترة → **ترحيل** بقيد تلقائي (مصروف رواتب / مستحقة + استقطاعات).

### 🛍️ 3-ك) نقطة البيع (POS) 🔒 `pos`
📄 شاشة بيع نقدي سريع + سلة.
- ⚙️ **بيع نقدي** يُرحَّل فوراً (صرف مخزني + قيد نقدي مباشر: الصندوق / المبيعات +
  ضريبة + تكلفة البضاعة) + **حساب الباقي** للعميل.

## 📑 4) التقارير

### 📑 4-أ) التقارير (Reports) 🔒 `reports`
📄 تبويبات تقارير:
- ✅ **ميزان المراجعة**
- ✅ **قائمة الدخل** (الأرباح والخسائر)
- ✅ **الميزانية العمومية** (متوازنة)
- ✅ **التدفقات النقدية**
- ✅ **الأستاذ العام** لأي حساب
- ✅ **تقرير الدعاوى** (تفصيلي/مجمّع مع المسدّد)
- ✅ **أعمار الديون** (Aging) للعملاء/الموردين
- ✅ **ضريبة القيمة المضافة** (مخرجات − مدخلات لكل فترة)
- ⚙️ **تصدير CSV** لأي تقرير.

### 🎯 4-ب) الموازنات التقديرية (Budgets) 🔒 `budgets`
📄 إدخال موازنة لكل حساب + تقرير المقارنة.
- ⚙️ **تحديد موازنة** تقديرية لحسابات الإيراد/المصروف.
- ✅ **تقرير الموازنة** = التقديري مقابل الفعلي + الانحراف.

## 🖥️ 5) النظام

### 👤 5-أ) المستخدمون والشركة (Admin) 🔒 `users` / `settings`
📄 تبويبات: المستخدمون · الأدوار · الشركة.
- ⚙️ **المستخدمون:** إضافة/تعديل/حذف + تعيين دور + تفعيل/إيقاف.
- ⚙️ **الأدوار:** إنشاء/تعديل/حذف دور + **تحديد صلاحياته** بالتفصيل.
- ⚙️ **بيانات الشركة:** عرض/تعديل + **إنشاء شركة جديدة** + **التبديل بين الشركات**.

### 🔗 5-ب) خرائط الترحيل (Posting Map) 🔒 `settings`
📄 شاشة ربط العمليات بالحسابات.
- ✅ تحديد **الحساب المستخدم تلقائياً** لكل عملية (العهد · الإقفال · الضريبة · الرواتب ·
  الشيكات…) — عشان القيود التلقائية تروح للحسابات الصح.

### 🔔 5-ج) التذكيرات (Reminders) 🔒 `reminders`
📄 قائمة التنبيهات + عدّاد في شريط الرأس.
- ⚙️ **إنشاء تذكير** يدوي + **توليد تلقائي** (أصناف تحت حد الطلب · سنوات مالية تنتهي قريباً).
- ⚙️ **تعليم كمُنجز** · **تجاهل** · **حذف**.

### 🛡️ 5-د) سجل التدقيق (Audit Log) 🔒 `audit`
📄 جدول كل العمليات الحساسة.
- ✅ **مين عمل إيه وإمتى** + القيمة **قبل وبعد** التعديل (شفافية كاملة للمراجعة).

### ⚙️ 5-هـ) الإعدادات (Settings) 🔒 `settings`
📄 شاشات إعدادات أساسية (لكلٍّ إضافة/تعديل/حذف):
- ⚙️ **الفروع**
- ⚙️ **السنوات المالية** (+ **إقفال/فتح** السنة)
- ⚙️ **العملات** (عملة أساسية واحدة)
- ⚙️ **مراكز التكلفة**
- ⚙️ **أنواع السندات**
- ⚙️ **الضرائب** (معطّلة افتراضياً وقابلة للتفعيل)
- ⚙️ **الإقفال السنوي:** قيود ختامية تلقائية (النتيجة → أرباح محتجزة) + قفل السنة.
