# ✅ قائمة اختبار الواجهة (Frontend)

## 🎯 اختبار المعلم (/grades/entry)

### تسجيل الدخول
- [ ] تسجيل الدخول ببيانات صحيحة
- [ ] تسجيل الدخول ببيانات خاطئة (رسالة خطأ)
- [ ] تسجيل الدخول بدون بيانات (Validation)

### عرض الفصول
- [ ] أزرار الفصول بألوان المراحل (🟡🟢🔴🔵)
- [ ] عرض عدد الطلاب لكل فصل
- [ ] عرض المادة لكل فصل
- [ ] اختيار الفصل والمادة

### رصد الدرجات
- [ ] جدول الطلاب يظهر بشكل صحيح
- [ ] عمود الأعمال (40) يظهر
- [ ] عمود الاختبار (60) يظهر
- [ ] Validation: ما ينفعش أكتر من 40/60
- [ ] Validation: كسر = نص درجة (0.5) بس
- [ ] خانة الطالب المعذور مقفولة (🔒)
- [ ] ألوان الدرجات حسب المستوى
- [ ] حفظ المسودة (زر حفظ)
- [ ] مؤشر الحفظ (أخضر/أصفر)

### الاعتماد
- [ ] زر اعتماد الأعمال
- [ ] زر اعتماد الاختبار
- [ ] ما ينفعش اعتماد قبل رصد كل الطلاب
- [ ] تأكيد قبل الاعتماد
- [ ] عدم القدرة على التعديل بعد الاعتماد
- [ ] إشعار لرئيس القسم بعد الاعتماد

- [ ] RTL (عربي) يعمل بشكل صحيح

- [ ] Responsive (موبايل + تابلت + ديسكتوب)

### الأداء
- [ ] تحميل الفصول (< 2 ثانية)
- [ ] تحميل الدرجات (< 2 ثانية)
- [ ] حفظ الدرجات (< 1 ثانية)
- [ ] اعتماد الدرجات (< 1 ثانية)
- [ ] طباعة الكشف (< 3 ثواني)

### الأمان
- [ ] غير مصرح = 403 Forbidden
- [ ] Token غير صالح = 401 Unauthorized
- [ ] بيانات غير مكتملة = 400 Bad Request
- [ ] بيانات غير موجودة = 404 Not Found
